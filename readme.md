# Documentation de la Machine à Café

## 1. Acteurs

- **Utilisateur (User)**
- **Manager**

## 2. Cas d'utilisation (Use Cases)

### C1 : Utiliser la machine à café
#### Étapes :
- Payer
- Choisir le type de café
- Récupérer le café

### Cas secondaires :
- **C2 : Payer**
- **C3 : Choisir le café**
- **C4 : Obtenir le café**

## 3. Diagrammes à inclure

- Diagramme de cas d'utilisation (Use Case Diagram) montrant les interactions entre :
  - L’utilisateur
  - Le manager
  - Les services

- Diagramme de classes (si nécessaire pour la modélisation)

## 4. Aspects métiers (Business)

- Modélisation du système
- Gestion des erreurs :
  - Pas de gobelet
  - Plus de café
  - Monnaie insuffisante
- Règles de gestion :
  - Le café coûte **1€**
  - Paiement par **pièces** ou **carte**

## 5. Services

- Gestion des paiements
- Choix du café
- Maintenance assurée par le manager

## 6. Modélisation

Utilisation de **UML** pour représenter :
- Cas d’utilisation
- Séquences *(facultatif)*
- Classes et objets *(facultatif)*

## 7. Erreurs possibles

- Manque d’eau
- Pas de gobelet
- Machine en panne
- Café non délivré
